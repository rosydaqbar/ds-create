# Base Components

Base Component child pages must remain in this exact order:

1. Avatars
2. Badges
3. Button groups
4. Buttons
5. Checkboxes
6. Dropdowns
7. Inputs
8. Progress indicators
9. Radio groups
10. Select
11. Sliders
12. Tags
13. Text editors
14. Toggles
15. Tooltips
16. Video players

# Shared canvas rules

- Use a private/unpublished zone at `x≈0` when private construction components exist.
- Public families generally begin at `x≈2800`.
- Place large `Design system header` instances above each family/zone.
- Component sets begin around `y≈590–680` depending on header height.
- Display the full component matrix; do not reduce it to a few representative cards.
- Preserve public property names when extending an existing system.
- Private helpers should use a leading `_` naming convention.
- Optional long-form documentation uses a 1600 px frame at the far right.
