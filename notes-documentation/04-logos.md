# Logos — Complete Notes Coverage

**Relevance:** CONDITIONAL when logo/brand assets are in scope.

## 1. Centrally managed logo-image assets

Repeated logo/image assets should be centrally managed so one source update can propagate through mockups/components.

## 2. Licensing and commercial-use awareness

The source includes specific license claims for its own placeholders.

Do not reproduce those claims.

Builder adaptation:
- record source/license metadata for external marks;
- never imply third-party logos are freely usable;
- separate owned marks, fictional placeholders, and third-party trademarks.

## 3. Changing placeholder logos

Preserve the workflow:
- replace the shared source asset/fill;
- let usages update;
- avoid manually replacing each occurrence.

## 4. Optical logo sizing

Equal bounding boxes do not create equal perceived size.

Preserve:
- size logos optically;
- normalize perceived height/visual weight;
- wide, compact, circular, and irregular marks need different scaling;
- use shared containers for logo clouds;
- fine-tune outliers.

## 5. Expanded logo libraries

The source promotes an external logo pack.

Builder adaptation:
- exclude promotion/download material;
- import only approved user assets;
- do not silently add real company logos.

## 6. Trademark note

Third-party marks remain owned by their respective owners. Their presence in design documentation does not imply endorsement.

## 7. Generated documentation

When Logos are in scope, include:
- asset-source model;
- lockup variants;
- centralized replacement workflow;
- actual brand clear-space/usage constraints;
- optical-sizing guidance;
- third-party asset/licensing note.
