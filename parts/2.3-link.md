# 2.3 Link

A Link navigates to another page, section or resource through text. It works inline inside a sentence ("Read the billing terms") and standalone on its own line or in an action row ("View all"). It replaces the two link-style treatments that used to live inside the button set: the brand-colored link becomes `Tone=brand`, the gray link becomes `Tone=neutral`.

Use a Button (2.1) for actions that change data. Use a Link to go somewhere.

# 2. Published set and properties

Published set: `Link`

Variant name pattern: `Type=standalone, Size=md, Tone=brand, State=rest`

| Property | Type | Values | Default | What it changes |
| --- | --- | --- | --- | --- |
| `Type` | variant | `inline, standalone` | `standalone` | inline: always underlined, no icons; standalone: underline on hover/pressed, icons allowed |
| `Size` | variant | `sm, md, lg` | `md` | label style and icon size |
| `Tone` | variant | `brand, neutral` | `brand` | brand-colored or neutral text |
| `State` | variant | `rest, hover, pressed, focus, disabled` | `rest` | text color, underline, focus ring |
| `Label` | text | — | "Link text" | the visible text |
| `Show leading icon` | boolean | — | `false` | standalone only |
| `Show trailing icon` | boolean | — | `false` | standalone only |
| `Leading icon` | instance swap | icons | `link` | — |
| `Trailing icon` | instance swap | icons | `arrow-right` | use `arrow-up-right` / external-link for destinations outside the product |

Variant count: 2 types × 3 sizes × 2 tones × 5 states = **60 variants**.

There is no loading state: a Link navigates; if navigation takes time, the destination shows its own loading.

# 3. Anatomy

Standalone:

```text
Link
layout: Horizontal
align: Center
padding: 0
gap: link/gap/{Size}
width: Hug, height: Hug

├─ Leading icon                          optional (Show leading icon)
├─ Label                                 text, underline on hover and pressed
└─ Trailing icon                         optional (Show trailing icon)
```

Inline:

```text
Link
layout: Horizontal
padding: 0
└─ Label                                 text, always underlined
```

Auto Layout relationship:

| Node | Direction | Width | Height | Padding | Gap |
| --- | --- | --- | --- | --- | --- |
| `Link` | Horizontal, centered | Hug | Hug | none | `link/gap/{Size}` |
| `Label` | — | Hug | Hug (line height) | — | — |
| icons | — | Fixed | Fixed | — | — |

- A Link has no control height. Its height is the line height of its text style, so an inline Link sits on the same line as the body text around it without shifting it.
- The root has no padding, so inline Links do not push surrounding text.
- In code, an inline Link is real text inside the paragraph; the Figma instance is placed inside an Auto Layout text row for documentation.

# 4. Sizes and measurements

| Size | Standalone label | Inline label | Icon (standalone) | Gap |
| --- | --- | --- | --- | --- |
| `sm` | `type/body/sm/semibold` | `type/body/sm/regular` + underline | `size/icon/sm` = 16 | `space/xs` = 4 |
| `md` | `type/body/md/semibold` | `type/body/md/regular` + underline | `size/icon/md` = 20 | `space/xs` = 4 |
| `lg` | `type/body/lg/semibold` | `type/body/lg/regular` + underline | `size/icon/md` = 20 | `space/sm` = 6 |

- Inline links use the same size and weight as the sentence they sit in; only color and underline change. Standalone links use the semibold weight.
- A standalone Link placed in a row of Buttons uses the size whose text style matches the buttons' label (`sm` next to Button xs–md, `md` next to Button lg–xl) and is vertically centered in the row.
- Standalone Links on touch platforms reach `size/touch-min` through hit-area padding in code.

# 5. States

| State | What changes |
| --- | --- |
| `rest` | base color; inline underlined, standalone not underlined |
| `hover` | color moves to its hover token; standalone gains the underline |
| `pressed` | color moves to its pressed token; underlined |
| `focus` | rest color + `focus/default` ring around the root (radius `radius/xs`) |
| `disabled` | `color/text/disabled`; inline keeps its underline |

A Link has no background in any state. Hover and pressed feedback is the color change plus the underline. The root keeps a bound `color/fill/none` fill and clip content on so the focus ring renders.

# 8. Guidelines

## 8.1 Link or Button
Visual: two rows of the same screen — "View invoice" as a Link (goes to the invoice page) and "Pay invoice" as a Button (changes data). Rule: if it goes somewhere, it is a Link; if it does something, it is a Button. Never style one to look like the other; the role in code must match what people see.

## 8.2 Inline vs standalone
- Inline: inside a sentence, same size and weight as the text, always underlined so it never depends on color alone.
- Standalone: on its own line or in an action row, after the content it leads to; semibold; underline on hover.
- Visual: one paragraph with an inline link, one card with a standalone "View all".

## 8.3 Brand vs neutral tone
- `brand` is the default and the one people recognize as a link.
- `neutral` for dense secondary text: footers, captions, table metadata, "Forgot password?".
- Visual: footer with neutral links next to a body paragraph with a brand link.

## 8.4 Icons
- Trailing `arrow-right` for "continue to" standalone links ("View all").
- Trailing external-link icon only when the destination leaves the product or opens a new tab.
- Leading icons only when they identify the destination type (a document, a download).

## 8.5 Content
- The label names the destination ("Billing settings", "Release notes"), never "click here" or "read more" on its own.
- Standalone labels are short (up to four words); inline labels may wrap with the sentence.
- Inline links follow the sentence's case; standalone links follow the brand's case rule.

## 8.6 Accessibility
- The underline keeps inline links distinguishable without color.
- Text color meets text contrast against `color/surface/base` in every mode and state except disabled.
- Focus ring always visible.
- Avoid disabled links; remove the link or explain why the destination is unavailable. A disabled link is not focusable and is announced as unavailable.
- Links that open a new tab or download a file say so in their accessible name.

## 8.7 Do / don't
- Do: "Read the billing terms" with "billing terms" linked. Don't: "Click here" linked.
- Do: underline inline links. Don't: rely on color alone inside paragraphs.
- Don't: a Link that deletes, saves or submits.
- Don't: brand-tone links stacked densely in a footer; use neutral.

# 9. QA

Fail QA when:
- link treatments still live inside the Button set;
- `Link color` / `Link gray` names appear instead of `Tone=brand` / `Tone=neutral`;
- inline links are not underlined in every state;
- the root has padding or a control height that shifts surrounding text;
- hover and pressed use background tints instead of the text color change;
- focus is missing or does not render;
- the Link vs Button guideline visual is missing.
