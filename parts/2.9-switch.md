# 2.9 Switch

A Switch turns one setting on or off, and the change applies immediately. It is the track-and-thumb control itself; it has two constructions (default and slim) that share one property and state model.

The labeled switch (switch + label + supporting text) lives on 3.3 Choice field, which instances this Part. In the old structure this page's published component was a private base under a labeled public toggle; now the control is the Part and labeling is the Component's job.

# 2. Published set and properties

Published set: `Switch`

Variant name pattern: `Size=md, Type=default, Checked=false, State=rest`

| Property | Type | Values | Default | What it changes |
| --- | --- | --- | --- | --- |
| `Size` | variant | `sm, md` | `md` | width, height, thumb |
| `Type` | variant | `default, slim` | `default` | thumb inside a full track, or thumb over a thin rail |
| `Checked` | variant | `false, true` | `false` | thumb position and track color |
| `State` | variant | `rest, hover, focus, disabled` | `rest` | interaction treatment |

Variant count: 2 × 2 × 2 × 4 = **32 variants**.

Rules:
- `Checked` moves the thumb (Auto Layout alignment start → end) and recolours the track. Never use two different track components for off and on.
- `Type` is visual construction, not a different control: slim uses the same properties and states.

# 4. Sizes and measurements

| Size | Type | Width | Height | Inset | Thumb | Rail |
| --- | --- | --- | --- | --- | --- | --- |
| `sm` | default | `switch/width/sm` = 36 | `switch/height/sm` = 20 | `switch/inset` = 2 | `switch/thumb/sm` = 16 | — |
| `md` | default | `switch/width/md` = 44 | `switch/height/md` = 24 | `switch/inset` = 2 | `switch/thumb/md` = 20 | — |
| `sm` | slim | `switch/slim-width/sm` = 32 | 16 | 0 | 16 | `switch/slim-track/sm` = 10 |
| `md` | slim | `switch/slim-width/md` = 40 | 20 | 0 | 20 | `switch/slim-track/md` = 12 |

- `sm` pairs with `type/body/sm` labels, `md` with `type/body/md`.
- The switch reaches `size/touch-min` through hit-area padding in code; in settings rows the whole row is the hit target.

# 5. States and matrix layout

| State | What changes |
| --- | --- |
| `rest` | off: neutral track; on: brand track |
| `hover` | track moves to its hover child |
| `focus` | rest + `focus/default` ring around the track (slim: around the root) |
| `disabled` | disabled track, thumb keeps its fill without shadow |

Matrix:

```text
                              rest   hover   focus   disabled      ← columns: State
default  sm  Checked=false
             Checked=true                                            ← rows: Type × Size × Checked
         md  Checked=false / true
slim     sm  Checked=false / true
         md  Checked=false / true
```

`.Main`: `.Main/Switch thumb` in both types.

# 6. Token map

| Part | Checked=false | Checked=true |
| --- | --- | --- |
| Track fill — rest | `color/fill/neutral/track` | `color/fill/brand/solid` |
| hover | `switch/track/off-hover` → aliases `color/border/strong` | `color/fill/brand/solid/hover` |
| disabled | `color/fill/neutral/subtle/disabled` | `color/fill/neutral/subtle/disabled` |
| Thumb fill | `color/surface/base` | `color/surface/base` |
| Thumb border (slim) | `color/border/default` | `color/fill/brand/solid` |
| Thumb shadow | `elevation/raised` | `elevation/raised` (none when disabled) |
| Focus | `focus/default` | `focus/default` |

| Part | Token |
| --- | --- |
| Radius | `radius/full` |
| Inset | `switch/inset` → `space/xxs` |

`color/fill/neutral/track` has no hover child, so the off-hover track is a component token; change its alias to retune it.

The thumb stays the surface color in both modes; in the Dark mode `color/surface/base` resolves to the dark surface and the track tokens keep the contrast.

# 7. Guidelines

## 7.1 Switch or Checkbox
Visual: the same "Email notifications" choice in a settings page (Switch, saves immediately) and in a sign-up form (Checkbox, saved on submit). Rule: Switch when the change applies immediately; Checkbox when it waits for a submit or sits among other choices.

## 7.2 Anatomy: thumb part → Switch → Choice field
Show `.Main/Switch thumb` → `Switch` → the labeled switch on 3.3, with arrows, captioned "The Part owns the mechanics; the field owns the label."

## 7.3 On, off and states
- On is the thumb at the end and the brand track; off is the thumb at the start and the neutral track.
- Hover, focus and disabled for both, side by side.

## 7.4 Default vs slim
- Default for settings lists and forms.
- Slim for compact headers and toolbars where a full track feels heavy.
- Never mix the two in one list.

## 7.5 Labels
- Labels describe the setting, not the action: "Email notifications", not "Turn on email notifications".
- The label sits on the left and the switch on the right in settings rows; in forms the switch may lead.
- Don't use labels that are ambiguous when on ("Disable sync" on = ?).

## 7.6 Accessibility
- The switch is announced as a switch with "on" or "off".
- Space toggles it; focus is always visible.
- The on/off state is shown by thumb position, not color alone; the off track meets non-text contrast (3:1).

## 7.7 Do / don't
- Don't: a switch for a choice with more than two options.
- Don't: a switch in a form that needs a submit button.
- Don't: duplicate track or thumb drawings inside 3.3 instead of instancing this Part.
- Don't: change the thumb's size between on and off.

## 7.8 Maintenance
Change `.Main/Switch thumb` for the thumb, and the tokens in §6 for colors, to update every switch, including those inside 3.3 Choice field.

# 8. QA

Fail QA when:
- on and off are separate components or separate track drawings;
- the thumb is not an instance of `.Main/Switch thumb`;
- focus is missing;
- slim uses a different property or state vocabulary;
- a label or supporting text is part of this Part (it belongs to 3.3);
- property names from the old model remain (`Pressed`, `Toggle`, `Default` as a state).
