# 2.16 Divider

A Divider is a thin line that separates groups of content on the same surface: groups in a menu, sections in a card, groups of controls in a toolbar. It can carry a short centred label, such as "or", to separate alternatives.

Divider is its own Part so every separating line in the system — in Menu (3.6), Rich text editor (4.1), Video player (4.2), cards and forms — has the same colour, thickness and rhythm, and sits in a dedicated layer rather than as a loose line drawn into each component.

# 1. Purpose

- Separate groups that share a surface when spacing alone doesn't make the grouping clear.
- Separate alternatives with a labelled line ("or").
- Keep divider colour and thickness consistent across every component that uses one.

# 4. Property inventory

| Property | Type | Values | Default |
| --- | --- | --- | --- |
| `Orientation` | variant | `horizontal`, `vertical` | `horizontal` |
| `Emphasis` | variant | `primary`, `secondary`, `tertiary` | `tertiary` |
| `Show label` | boolean | — | false |
| `Label` | text | — | "or" |

Variants: `Orientation` 2 × `Emphasis` 3 = 6, e.g. `Orientation=vertical, Emphasis=tertiary`.

`Emphasis` is the line's visual weight:

| Emphasis | Line | Use |
| --- | --- | --- |
| `primary` | strong border colour, 2 thick | separating major regions inside one surface |
| `secondary` | default border colour, 1 thick | separating groups that must stay clearly distinct |
| `tertiary` (default) | subtle border colour, 1 thick | list rows, menu groups, card sections, toolbars |

`Show label` applies to `horizontal` only; a vertical Divider never shows a label.

# 5. Anatomy

```text
Divider
layout: Horizontal
align: Center
gap: space/md (only when the label is shown)
width: Fill (horizontal) / Hug (vertical)
height: Hug (horizontal) / Fill (vertical)

├─ Start line                         frame with no fill and one inside stroke (top side; left side when vertical)
├─ Label                              optional (Show label); horizontal only
└─ End line                           same as Start line; shown only with the label
```

Construction rules:
- Each line is a frame whose thickness equals its stroke width, with a single inside stroke on one side, so the line is exactly one stroke thick and binds a border token.
- With `Show label` off, only `Start line` is visible and it spans the whole Divider.
- With `Show label` on, `Start line` and `End line` share the remaining width equally and the Label sits centred between them.
- The Divider has no margin. The space before and after it comes from the parent's gap or from a dedicated wrapper in the parent (the toolbar in 4.1 places each vertical Divider in a `Divider wrapper` so the rhythm is the same around every divider).

# 10. Guidelines content

Topics for `2.16 Divider · Guidelines`, in order. Each visual uses real Divider instances inside real compositions.

## Spacing first, then a Divider

Space and alignment separate most groups. Add a Divider only when groups sit on the same surface and spacing alone doesn't make the break clear — long menus, dense settings, toolbars.

Visual — Do/don't pair (`Doc/Do-dont`):
- Don't: a short form with a Divider between every field.
- Do: the same form grouped with spacing, and one Divider before the "Danger zone" section.

## Choosing the weight

Use `tertiary` by default. Move to `secondary` or `primary` only when a stronger break is needed, and keep one weight per surface.

Visual — the same card with three sections shown with `tertiary` dividers and, as a Don't, with mixed weights.

## Horizontal and vertical

Horizontal dividers separate rows and sections. Vertical dividers separate groups of controls in a toolbar or inline metadata ("Updated 2 h ago | 3 comments"). A vertical Divider fills the height of its row; it is never taller than the controls next to it.

Visual — the editor toolbar from the Overview with `Doc/Measure` showing the vertical divider matching the row height.

## Labelled dividers

Use the label to separate alternatives ("or") or to name a group in a long list. Keep it to one or two words.

Visual — the sign-in alternatives composition, with a Don't version labelled "Or you can also sign in with your email address below".

## Dividers don't frame regions

Don't use dividers above and below a block to make it look like a card. If a region needs to stand apart, give it a surface or a border on its container.

Visual — Don't: a settings block boxed in by four dividers. Do: the same block on `color/surface/raised` with `radius/surface`.

## Content

- Labels are lower-case or sentence case, one or two words, and never wrap.
- Don't put actions inside a Divider label; place a Button beside the content instead.

## Accessibility

- A Divider that only adds visual structure is hidden from assistive technology.
- When it separates groups the user moves between, such as menu groups, it is exposed as a separator.
- A labelled Divider exposes its label as text, so "or" is announced.
- Lines are decorative unless they are the only boundary of a region; in that case the line meets the non-text contrast threshold.

# 11. QA

Fail QA when:
- components draw their own loose lines instead of instancing `Divider`;
- a divider is a filled rectangle or a vector instead of a frame with a bound stroke;
- the Divider carries its own margin, so space above and below differs between components;
- a vertical Divider shows a label or is taller than the row it sits in;
- `Start line` and `End line` are unequal when the label is shown;
- different weights are mixed on one surface in the documentation examples;
- colours and thickness are raw values instead of `color/border/*` and `border/width/*`.
