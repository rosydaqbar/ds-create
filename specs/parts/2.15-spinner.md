# 2.15 Spinner

A Spinner shows that something is loading when the amount of work or the time left is unknown. It is a background ring with a rotating active segment.

Spinner is the system's one loading indicator. Button (2.1) and Icon button (2.2) instance it in their `State=loading` variants, so a change to the Spinner updates every loading button at once. It is also used on its own where content is about to appear: a panel, a table, a whole region.

Use Progress (2.14) when the amount of work is known.

# 1. Purpose

- Show indeterminate loading with one consistent shape everywhere.
- Give Button and Icon button a reusable loading helper that keeps their action identity.
- Stand in for content that is on its way, at the size of that content.

# 4. Property inventory

| Property | Type | Values | Default |
| --- | --- | --- | --- |
| `Size` | variant | `sm`, `md`, `lg`, `xl` | `md` |
| `Tone` | variant | `neutral`, `brand` | `neutral` |

Variants: `Size` 4 × `Tone` 2 = 8, e.g. `Size=md, Tone=brand`.

- `sm` and `md` are the in-control sizes; Button and Icon button use them.
- `lg` and `xl` are for standalone loading in panels and regions.
- Inside Button and Icon button, the parent overrides the color of both rings with its own label color (§5), so `Tone` only matters for standalone use.

# 5. Anatomy

```text
Spinner
layout: none (positioned composition)
size: icon box of the Size (square)

├─ Background ring                    full ellipse, stroke only, stroke inside
└─ Active segment                     arc of 90° starting at 12 o'clock, clockwise; stroke inside; round caps
```

Construction rules:
- Both rings are ellipses the full size of the box with the stroke aligned inside, so the Spinner never exceeds its box and lines up with icons of the same size.
- The Active segment is the same ellipse as the Background ring with an arc sweep; it is not a separate drawn path.
- Rotation is applied to the Active segment around the center of the box; the Background ring doesn't move.

## Use inside Button and Icon button

The parent:
1. instances `Spinner` with `Size` matching its icon box (`sm` where the button's icon is `size/icon/sm`, `md` where it is `size/icon/md`);
2. binds the Active segment stroke to its own label color for that emphasis and tone, and the Background ring to the same color at the parent's track role (`color/fill/neutral/track` on light fills; the label color at reduced opacity on solid fills), so the Spinner matches the label it replaces on every fill;
3. keeps its own size: the Spinner sits in the place of the leading icon, and the label switches to the loading text ("Saving…") or stays, as defined in the parent's file.

The Spinner does not create a separate loading family for buttons; the loading state is a `State` value of each button.

## Auto Layout relationship

The Spinner has no Auto Layout; it is a fixed square that a parent places like an icon. In a standalone composition it is the first child of a vertical stack (`gap: space/md`, centered) with the loading text below it.

## Flexible vs fixed children

| Layer | Horizontal | Vertical |
| --- | --- | --- |
| `Spinner` (root) | Fixed (icon box) | Fixed (icon box) |
| `Background ring` | Scale with the root | Scale with the root |
| `Active segment` | Scale with the root | Scale with the root |

# 6. Sizes and measurements

| Size | Box | Ring thickness | Used in |
| --- | --- | --- | --- |
| `sm` | `size/icon/sm` = 16 | 2 | Buttons and Icon buttons with 16 icons; inline with `type/body/sm` text |
| `md` | `size/icon/md` = 20 | 2 | Buttons and Icon buttons with 20 icons; inline with `type/body/md` text |
| `lg` | `size/icon/xl` = 32 | 4 | cards, panels, table bodies |
| `xl` | 48 | 6 | a whole region or empty page area |

Ring thickness lives in `spinner/thickness/{size}`. Standalone loading text sits `space/md` = 8 under the Spinner, in `type/body/sm/medium`, `color/text/tertiary`.

# 7. States

The Spinner has no interaction states. It is either shown (loading) or removed.

# 10. Guidelines content

Topics for `2.15 Spinner · Guidelines`, in order. Each visual uses real Spinner, Button and Icon button instances.

## Spinner or Progress

Use a Spinner when loading takes long enough to notice and its length is unknown. When the amount of work is known, use Progress (2.14); when it becomes known part-way, switch to Progress.

Visual — side by side: Spinner "Loading invoices…" and Progress "Uploading 3 files · 40%", each captioned with the question "Do you know how much is left?".

## Loading inside a button

When an action starts work, put the button into `State=loading`. The Spinner appears inside it in the label color, the button keeps its size, and it can't be pressed twice. Don't place a separate Spinner next to the button, and don't disable the button without telling users why.

Visual — Do/don't pair (`Doc/Do-dont`):
- Don't: a disabled Button "Save changes" with a Spinner floating to its right.
- Do: the Button in `State=loading` with "Saving…".

## Size from the content it replaces

Place the Spinner where the content will appear and size it to that content: `sm`–`md` inline with text and in controls, `lg` in cards and panels, `xl` for a whole region. One Spinner per region; don't scatter spinners in every row of a loading list.

Visual — a card at three moments: loading with Spinner `lg` in the body, loaded with content, and a Don't version with a Spinner in every row.

## Short waits and long waits

For waits under about one second, show nothing; a flash of a Spinner feels slower than none. For long waits, add text that says what is happening ("Preparing your export…") and, after a while, what users can do ("You can leave this page; we'll email you.").

Visual — a timeline: 0–1 s nothing, 1–10 s Spinner with text, 10 s+ Spinner with text and a follow-up line.

## Tone

Use `neutral` by default. Use `brand` only when the Spinner is the main thing on screen, for example a full region loading.

Visual — a table loading with a neutral Spinner, and a start screen loading with a brand Spinner.

## Motion and reduced motion

The Active segment rotates continuously at a constant speed. Rotation is the only signal that work is in progress, so with reduced motion the Spinner keeps rotating at half speed instead of stopping; the loading text carries the meaning as well.

Visual — a filmstrip of four frames of the rotation, with the reduced-motion version showing the same frames at a longer interval.

## Content

- Loading text is short and specific, with an ellipsis: "Loading invoices…", "Saving…".
- Don't write "Please wait" on its own; say what is loading.

## Accessibility

- A standalone Spinner has a status role and an accessible name ("Loading invoices"); announce completion through the content that replaces it.
- Inside a Button or Icon button, the button exposes the busy state and keeps its accessible name; the Spinner itself is hidden from assistive technology.
- The Active segment meets the non-text contrast threshold against the surface or the parent's fill in every color mode.

# 11. QA

Fail QA when:
- a Button or Icon button draws its own loading rings instead of instancing `Spinner`;
- the Spinner is larger than its icon box because its stroke is centered or outside;
- the Active segment is a separate path instead of an arc of the ring ellipse;
- inside a button the Spinner keeps a fixed color that doesn't match the button's label on every emphasis and tone;
- a loading button changes size compared with the same button at rest;
- a separate "loading button" set exists instead of `State=loading` on Button and Icon button;
- colors and thickness are raw values instead of the tokens in §9.
