# 2.7 Checkbox

The Checkbox Part is the box itself: unchecked, checked or mixed (partly checked). It lets people pick any number of options from a set, or confirm one statement. The box is reused by tables, lists, tags and menus.

The labeled checkbox (box + label + supporting text) lives on 3.3 Choice field, which instances this Part. The radio control is a separate Part on 2.8 Radio and shares this Part's sizes, border, fill and focus tokens so both read as one family.

# 2. Published set and properties

Published set: `Checkbox`

Variant name pattern: `Size=md, Checked=false, State=rest`

| Property | Type | Values | Default | What it changes |
| --- | --- | --- | --- | --- |
| `Size` | variant | `sm, md` | `sm` | box side, radius, mark size |
| `Checked` | variant | `false, true, mixed` | `false` | empty box, check mark, or minus mark |
| `State` | variant | `rest, hover, focus, disabled` | `rest` | interaction treatment |

Variant count: 2 sizes × 3 checked × 4 states = **24 variants**.

# 3. Anatomy

```text
Checkbox
layout: Horizontal
align: Center / Center
size: checkbox/size/{Size} square (Fixed)
radius: checkbox/radius/{Size}
border: border/width/default
clip: on (for the focus ring)

└─ Mark                                 icon instance: check (Checked=true) or minus (Checked=mixed); absent when Checked=false
```

The box owns shape, border, checked fill, focus ring, disabled treatment and the alignment of the check and minus marks. Unchecked variants contain no mark child.

Auto Layout relationship:

| Node | Direction | Width | Height |
| --- | --- | --- | --- |
| `Checkbox` | Horizontal, centered | Fixed | Fixed |
| `Mark` | — | Fixed `checkbox/mark/{Size}` | Fixed |

Nothing grows. The mark is centered optically: the check glyph is nudged so its visual weight sits in the middle of the box.

# 4. Sizes and measurements

| Size | Box | Radius | Mark |
| --- | --- | --- | --- |
| `sm` | `checkbox/size/sm` = 16 | `checkbox/radius/sm` → `radius/xs` = 4 | `checkbox/mark/sm` = 12 |
| `md` | `checkbox/size/md` = 20 | `checkbox/radius/md` → `radius/sm` = 6 | `checkbox/mark/md` = 14 |

- `sm` pairs with `type/body/sm` labels; `md` pairs with `type/body/md` labels (3.3 Choice field).
- In lists and tables the whole row is the hit target; on its own, the box reaches `size/touch-min` through hit-area padding in code.

# 5. States and matrix layout

| State | What changes |
| --- | --- |
| `rest` | unchecked: surface + border; checked/mixed: brand fill + on-solid mark |
| `hover` | unchecked: border and fill tint toward brand; checked/mixed: fill moves to its hover child |
| `focus` | rest + `focus/default` ring |
| `disabled` | disabled fill, border and mark |

Matrix:

```text
                       rest   hover   focus   disabled      ← columns: State
sm   Checked=false
     Checked=true                                             ← rows: Size × Checked
     Checked=mixed
md   Checked=false … mixed
```

# 7. Guidelines

## 7.1 Checkbox, Radio or Switch
Visual: three settings blocks side by side — notification channels (Checkbox, many can be on), plan billing period (Radio, exactly one), "Dark mode" (Switch, applies immediately). Rule: Checkbox for any number of choices or a single confirmation submitted with a form.

## 7.2 Unchecked, checked and mixed
- Mixed (partly checked) only appears on a parent whose children are partly checked. Clicking a mixed parent checks all children.
- Mixed is never an end-state a user picks directly.
- Visual: the nested list from Overview with arrows from the children to the parent's mark.

## 7.3 Size
`sm` in dense tables, menus and tags; `md` in forms and settings. One size per list.

## 7.4 Labels and hit targets
- In product, a checkbox almost always has a visible label (3.3 Choice field). An unlabeled box is only acceptable when the row or column header labels it (tables).
- The label and the box are one hit target.
- Visual: a table row where the whole row toggles selection, with the hit area outlined.

## 7.5 Accessibility
- Checked and mixed are shown by the mark, not by color alone.
- Focus ring is always visible; Space toggles the box.
- Mixed is announced as "mixed" (partly checked).
- The unchecked border meets the non-text contrast threshold (3:1) against the surface.

## 7.6 Do / don't
- Do: Checkbox for multiple choices. Don't: Checkbox for a single choice among several (use Radio).
- Don't: an unlabeled checkbox outside tables.
- Don't: mixed on a child item.
- Don't: a checkbox that applies a setting immediately without a submit (use Switch).

## 7.7 Maintenance
Edit the tokens in §6 or this set to change every checkbox in the system, including those inside tags, menus, tables and Choice fields.

# 8. QA

Fail QA when:
- the mixed mark is missing;
- focus is missing from any Checked value;
- a label or supporting text is part of this Part (it belongs to 3.3);
- Checkbox and Radio use different border, fill or focus tokens;
- marks are drawn as vectors per variant instead of icon instances;
- property names from the old model remain (`Indeterminate`, `Type=Checkbox/Radio`, `Default`, `Focused`).
