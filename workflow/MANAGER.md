# DS Create Builder

DS Create Builder is the builder's local workspace for init. Its documentation is split into four files.

- [builder/lifecycle.md](builder/lifecycle.md): start, identity and progress, what appears, init handoff, saving and undo, sync state, motion.
- [builder/publish.md](builder/publish.md): the Publish panel, Figma generation, MCP delivery and recovery.
- [builder/parts.md](builder/parts.md): Parts in Builder.
- [builder/setup.md](builder/setup.md): web-first setup, source revisions and the foundation plan.
