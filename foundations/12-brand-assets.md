# ↳ Brand Assets


> **Initiator gate:** Execute this specification only when this Foundation is in scope. If it already exists, apply the confirmed action (`Keep`, `Audit`, `Improve`, `Refactor`, `Rebuild`, or `Replace`) before changing anything. Actual token names must follow the naming system selected in the initiator; token names shown here are logical roles.

This page provides slots and construction rules for brand assets without assuming a specific brand.


## Figma documentation layout

Document this Foundation using the complete documentation-frame system in `01-documentation-system.md`.

Use a `2848 px` overview frame when the topic is primarily visual/specimen-based, a `2528 px` specification frame when it is primarily variable/table-based, and an optional `1600 px` notes frame only when deeper guidance is genuinely useful.

Every major section starts with a `720 px` Design note followed by the relevant specimen/table after `64 px`.

Do not generate separate `Source`, `Matrices`, or `QA` utility boards as the primary presentation.

## Required asset groups

```text
Logo / Symbol
Logo / Wordmark
Logo / Lockup / Horizontal
Logo / Lockup / Vertical
Logo / Monochrome
Logo / Inverse
App icon
Favicon
```

Only create groups that the actual brand supplies.

## Clear-space documentation

Use a named clear-space token derived from a stable feature of the supplied mark.

Do not invent brand geometry before assets are provided.

## Overview specimen content

Inside the documentation Section, present the approved assets as clearly labeled specimen rows:

```text
Master artwork
Approved lockups
Monochrome variants
Digital app assets
```

Each row begins with a compact Design note and shows the real asset instances to the right.

## Rules

- do not stretch marks;
- do not recolor beyond approved semantic mappings;
- do not recreate supplied logo artwork with a substitute typeface;
- do not publish placeholder brand marks in a production library.
