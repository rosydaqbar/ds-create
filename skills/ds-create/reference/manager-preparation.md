# Local preparation · parse, bind, compile

For preparationVersion:2 this is the complete normal runtime contract. AI parses source facts and necessary exceptions; Node fills premade foundation templates. Do not load global init/generation/Figma/build/consumer-docs handbooks for this local job.

1. Read the trusted request and source-pack.json once. Read all extracted evidence before asking questions. Inspect flagged originals using existing native file/image tools; import token exports losslessly. Listed `../filename` entries refer ONLY to direct workspace/input/ files. Never traverse another system or execute source code.
2. Fill the server-created foundation-inputs.json structure into decisions.json beside the request. template-catalog.json contains the6fixed template ids and input fields. Keep inputHash/inputRevision and coverage path/hash identities exact. Parse product meaning and supplied values; record source-backed exceptions. Do not generate per-system renderer code, derived primitive tables, Markdown summaries or hundreds of variable/style definitions.
3. Invoke the owned compile action. Node expands templates, validates source/aliases/contrast, writes canonical draft/plan and paired JS/MD files, then returns a receipt. Correct only the named input/error and compile again. Ready is decided by the existing proof checks, not a message.
4. Finish ready/questions/blocked/failed/cancelled through the same owner. After finish, end the main agent turn; Node waits. No idle AI polling, subagents, Figma, font installation/substitution, approval or build.

## Input binding

The source pack locks projectName, selected appearance modes and platform. Keep those choices. Latest context supersedes conflicting older context; newest active uploads supersede their archived filename versions. Standing knowledge/frozen library values precede defaults. Explicit source values remain unchanged. Distinguish the product's tokens from the HTML brief's own presentation styles.

Normal included scope:

```json
{"status":"included","template":"04-radius","inputs":{"preset":"square"}}
```

| Domain | Premade pair | Parse only these inputs when supplied |
| --- | --- | --- |
| color | 01-color.js + .md | palette anchors/purpose, tone roles, explicit semantic overrides |
| typography | 02-typography.js + .md | exact families; faces per family (e.g. display.regular = Roman); supplied scale rows |
| space | 03-spacing.js + .md | base unit, explicit spacing/size/grid exceptions |
| shape | 04-radius.js + .md | square/soft preset, explicit radius/border exceptions |
| elevation | 05-shadow.js + .md | none/flat/layered treatment, supplied effect exceptions |
| motion | 06-motion.js + .md | only explicit duration/easing/delay exceptions |

Defaults, alias naming, scopes, code syntax, primitive expansion and style bindings belong to the template/compiler. A none depth treatment retains accessible zero-blur focus outlines. Family-specific face names require no hand-built duplicate styles/variables. Default scale rows use only the declared faces; a supplied custom row requesting an undeclared face is a real conflict.

Timings in recipe inputs use milliseconds; Node emits native TIMING seconds. Easing compiles to native EASING objects. New systems retain basic Standard/Reduced UI motion and Lucide utility icons; an illustrative/screen-animation exclusion does not remove these baselines. A genuinely static UI records sourced zero timings. No illustrative art/components are generated.

Set product{name,description,platform}, systemMode:new|existing, naming:normalize|keep, source coverage and decisions in the same decision file. Product purpose must come from input, including YOLO. Decisions use {key,value,decidedBy:user|AI,source}; AI inferences also need a concise reason. Ask only genuinely missing/conflicting choices in Builder. Unspecified UI font suggestions: Inter, Geist, Plus Jakarta Sans. Preserve selected exact font identities without availability checks here.

Coverage accounts for each snapshot once: path/hash/status read|inspected|imported|archived, with notes for inspections/imports; archives only when actually archived. `unreadable` plus actual evidence is allowed only with questions. A listed file is not proof it was read.

Excluded domains require status:excluded, source and reason. Preserve frozen existing exports/naming through frozenSource and the lossless importer. Legacy recipe/extra definitions remain supported. Read `manager-preparation-recipes.md` ONLY for an existing non-template recipe, frozen import or a supplied exception the normal fields cannot express; never rewrite a supplied export to fit a preset.
